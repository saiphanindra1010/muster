A colleague, not a new chat box

Each bot has a name, a face, and its own conversation. You pick who does the work.

Name it first

New bot asks for a name and a face. Nothing is created until you press Create.

It stays on the job

A bot keeps working in the background. Come back to the reply when you are ready.

Light and dark

Follow the system, or pin Light or Dark. The choice is remembered on this computer.

Install it like any other app

One installer per system. The engine ships inside the app, so there is nothing else to set up.

Mac

Open the disk image and drag Muster to Applications.

Muster.dmg
Windows

Run the setup wizard. It adds a Start menu shortcut and an uninstaller.

Muster-setup.exe
Linux

Install the package with your software center, or with apt.

Muster.deb
