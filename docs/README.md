# Muster docs

Muster is a desktop app where each bot is an OpenCode agent on a headless
`opencode serve` harness. Bots behave like colleagues: their own chat, skills
and connector access, running in the background - the engine stays invisible.

| Doc | What's inside |
| --- | --- |
| [architecture.md](architecture.md) | Processes, data flow, harness protocol, storage, auth |
| [development.md](development.md) | Setup, dev loop, ports, sandboxing, verification, builds |
| [design.md](design.md) | Design language, tokens, themes, chat anatomy, copy rules |
| [bots.md](bots.md) | Bot file format, personas, skills, MCP rules, the marketplace |

The [root README](../README.md) is the quick start; these docs go one level
below it.
